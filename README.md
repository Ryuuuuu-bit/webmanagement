# TeachSchedule — ระบบตารางสอนอาจารย์ (หลาย site/สาขา)

ระบบปิดใช้ภายในองค์กร (Admin สร้างบัญชีให้ ไม่มีสมัครเอง) จัดการตารางสอน เช็คอิน-เอาต์ตาม GPS การลา การรับรองเวลา
และแผนการสอนของอาจารย์ ข้อมูลเฉพาะองค์กรทั้งหมด (สาขาวิชา วิชา ห้อง ภาคเรียน จุดเช็คอิน โควต้าวันลา นโยบายเช็คอิน)
ตั้งได้จากหน้าเว็บ คู่มือผู้ใช้อยู่ที่ [`docs/`](./docs/)

Stack: Next.js 14 (App Router) · Prisma + PostgreSQL · NextAuth · Tailwind · deploy บน Railway

## ฟีเจอร์โดยย่อ

- **บัญชี** — login ด้วย username/รหัสผ่าน หรือ passkey (Face ID/ลายนิ้วมือ) · Admin สร้างบัญชี/รีเซ็ตรหัส/QR ผูกเครื่อง/
  แก้ไขข้อมูลทุกช่อง/ระงับ/ลบ/นำเข้าจาก Excel · หน้ายินยอม PDPA ครั้งแรก · รหัสชั่วคราวหมดอายุ 7 วัน มีแถบเตือนให้ตั้งรหัสเอง (ไม่บังคับก่อนเข้าแอป) · ไม่มีลืมรหัสผ่านแบบทำเอง
  (แอดมินรีเซ็ต) · ล็อกบัญชีเมื่อ login ผิดหลายครั้ง · ประวัติความปลอดภัย (Audit Log)
- **เช็คอิน-เอาต์** — ต้องอยู่ในรัศมี site ประจำของอาจารย์ · นโยบายกันเช็คอินแทน: บังคับไบโอเมตริก, อุปกรณ์ต้องอนุมัติ
  (1 เครื่อง/คน), เซลฟี่, ตรวจจับมือถือเครื่องเดียวใช้หลายบัญชี · กดได้จาก Dashboard และหน้าเช็คอิน · Admin แก้เวลา/ลบ/ดูประวัติได้
- **ตารางสอน** — ปฏิทินสไตล์ Teams (สัปดาห์/วันทำงาน/วัน กรองภาคเรียน) ตรวจจับจองซ้ำ
- **การลา / รับรองเวลา / แผนการสอน** — workflow ขอ→อนุมัติ · โควต้าวันลาต่อปีต่อประเภท (เตือนเมื่อเกิน) · ลาครึ่งวัน · แนบเอกสาร ·
  ยกเลิกคำขอเอง · อัปโหลดไฟล์แผนการสอน
- **การแจ้งเตือน** — ทุกขั้นตอนขอ/อนุมัติ, อุปกรณ์รออนุมัติ, เปลี่ยนตารางสอน/สิทธิ์/site, รหัสชั่วคราว · กระดิ่ง + หน้า
  แจ้งเตือน + กล่องเด้งขณะเปิดแอป · Web Push เด้งบนมือถือแม้ปิดแอป (ตั้ง VAPID) · ข้อความตามภาษาผู้อ่าน
- **อื่นๆ** — TH/EN · Light/Dark · PWA ติดตั้งบนมือถือ (session 90 วัน) · responsive PC/มือถือ · Master Data · จุดเช็คอินบนแผนที่

## เริ่มต้น

```bash
npm install
cp .env.example .env      # ตั้งค่าตามคอมเมนต์ในไฟล์
npx prisma db push        # ไม่ใช้ migration history
npm run prisma:seed       # ข้อมูลตัวอย่าง (ไม่บังคับ)
npm run dev
```

`npm start` (production) รัน `prisma db push` → สคริปต์บำรุงรักษาใน `scripts/` (ทำงานเฉพาะเมื่อตั้ง env) → `next start`

ตัวแปร `.env`: `DATABASE_URL`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL` (จำเป็น) · `TZ=Asia/Bangkok` · `GOOGLE_PLACES_API_KEY`
(ค้นหาชื่อสถานที่) · `RESEND_API_KEY`/`EMAIL_FROM` (ส่งลิงก์ตั้งรหัสทางอีเมล — ไม่บังคับ) · `SEED_DEMO_USERS`,
`DELETE_USERS`/`MAINTENANCE_TOKEN` (token ใช้ครั้งเดียวสำหรับสคริปต์บำรุงรักษา) · `VAPID_*` (Web Push) — รายละเอียดใน `.env.example`

## ก่อนทดสอบเช็คอิน

ต้องเป็น HTTPS (GPS/กล้อง/WebAuthn) · มีจุดเช็คอินอย่างน้อย 1 จุด (`/admin/locations`) · กำหนด site ประจำให้อาจารย์
(`/admin/users`) · นโยบายเริ่มต้นเข้มสุด ปิดชั่วคราวได้ที่หน้าเช็คอินของ Admin · passkey ผูกกับโดเมน
